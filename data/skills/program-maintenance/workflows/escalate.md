# 升级 L3 流程

遇到以下情况，不要继续修复，直接报告升级原因：

- 需要停站、关机、重启核心服务或修改关键网络入口。
- 需要修改 `/etc/ssh/`、防火墙、数据库、证书或生产流量配置。
- 失败表现像攻击、异常流量、入侵、资源耗尽或数据损坏。
- 当前 Skill 不知道业务目标，继续操作可能扩大影响。
- 多次低风险修复无效。

对应 disposition：

- 超出能力边界：`out_of_scope`
- 操作风险过高：`risk_too_high`
- 需要用户业务决策：`needs_human_decision`
- 疑似事故/攻击：`suspected_incident`
